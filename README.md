# 🇪🇸 Español

## Descripción

QR Code Generator Web es una aplicación web desarrollada con HTML, JavaScript y Canvas que permite generar códigos QR a partir de texto o enlaces.

Incluye funciones para copiar el QR como imagen al portapapeles y descargarlo en formato JPG.

## Características

* Generación de códigos QR en tiempo real.
* Soporte para texto y enlaces.
* Copiar QR como imagen al portapapeles.
* Descargar QR en formato JPG.
* Interfaz simple y ligera.
* Uso de Canvas para manipulación de imágenes.
* Compatible con navegadores modernos.

## Tecnologías Utilizadas

* HTML
* CSS
* JavaScript
* Canvas API
* Clipboard API
* QRCode.js (librería externa)

## Instalación

No requiere instalación.

Solo abrir el archivo:

```text id="qr9"
index.html
```

## Uso

1. Escribir texto o enlace.
2. Presionar "Generar QR".
3. Opcional:

   * Copiar imagen del QR al portapapeles.
   * Descargar QR como imagen JPG.

## Funciones

### Generar QR

Convierte el texto ingresado en un código QR visual.

### Copiar QR

Copia la imagen del QR al portapapeles usando Clipboard API.

### Descargar QR

Permite guardar el QR como archivo JPG con fondo blanco.

## Compatibilidad

* Google Chrome
* Microsoft Edge
* Brave
* Otros navegadores modernos

# 🇺🇸 English

## Description

QR Code Generator Web is a web application built with HTML, JavaScript, and Canvas that generates QR codes from text or links.

It also allows copying the QR as an image to the clipboard and downloading it as a JPG file.

## Features

* Real-time QR code generation.
* Supports text and URLs.
* Copy QR image to clipboard.
* Download QR as JPG.
* Lightweight and simple UI.
* Canvas-based image processing.
* Modern browser compatible.

## Technologies Used

* HTML
* CSS
* JavaScript
* Canvas API
* Clipboard API
* QRCode.js library

## Installation

No installation required.

Just open:

```text id="qr10"
index.html
```

## Usage

1. Enter text or URL.
2. Click "Generate QR".
3. Optional:

   * Copy QR image to clipboard.
   * Download QR as JPG.

## Features Breakdown

### Generate QR

Converts input text into a visual QR code.

### Copy QR

Copies QR image to clipboard using Clipboard API.

### Download QR

Saves QR as a JPG image with white background.
